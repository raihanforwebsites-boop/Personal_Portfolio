# Raihan — Portfolio

A personal portfolio site built to give recruiters, hiring managers, and admissions readers a fast, credible view of my work at the intersection of **economics, data, and business strategy**.

**Live site:** `https://raihanforwebsites-boop.github.io/Personal_Portfolio/`

## What's here

- **About** — background, research credentials, target roles
- **Research** — published paper (fisheries livelihood vulnerability, Scopus/WoS-indexed), an in-progress EPW Letter, and the Yale Financial Markets certificate
- **Projects** — seven analytical projects spanning econometrics (ARDL, Harrod–Domar, ordered logit), SQL, and Power BI
- **Experience** — internships at CirroCraft, JSW Steel, and MoveABox
- **Skills** — Stata, EViews, Python, SQL, Excel, Power BI/DAX

## Stack

Plain HTML, CSS, and vanilla JavaScript. No frameworks, no build step, no dependencies beyond Google Fonts (with system-font fallbacks). Deploys directly as a static site via GitHub Pages.

```
├── index.html
├── styles.css
└── script.js
```

## Deployment

Settings → Pages → Deploy from a branch → `main` → `/root`.
